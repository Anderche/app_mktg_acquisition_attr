# Top Features

- Channel KPIs: users, sessions, conversions, revenue, CVR, AOV.
- Attribution comparison: last-click, first-click, linear, Markov.
- Markov removal effects per channel.
- Sankey diagram of top conversion paths.
- Campaign leaderboard with sorting, search, CSV export.
- Global filters: date, device, country.
- Sub-second loads from pre-aggregated DuckDB tables.
- Colorblind-safe palette with light/dark themes.
- Data sources and limitations panel.
